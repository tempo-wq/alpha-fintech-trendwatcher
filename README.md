# Fintech Trendwatcher MVP

Модуль автоматизированного сбора, семантической дедупликации и экспертного анализа рыночных сигналов. Проект предназначен для мониторинга новостей финансового сектора, фильтрации информационного шума и формирования структурированных аналитических дайджестов.

## Основной функционал

- **Умный парсинг (RSS):** Автоматический сбор новостей из профильных источников, таких как Банк России, Banki.ru и VC.ru.
- **Семантическая дедупликация:** Выявление дублирующихся новостей с использованием эмбеддингов (`paraphrase-multilingual-MiniLM-L12-v2`) и косинусного сходства (Cosine Similarity).
- **LLM-Аналитика:** Обработка текстов через OpenAI API (модель `gpt-4o-mini` через OpenRouter) для извлечения ключевых фактов, оценки значимости события и формирования черновиков.
- **Гибридный скоринг:** Оценка «горячести» (hotness) новости на основе выводов нейросети и эвристических правил (наличие триггерных слов и авторитетность источника).
- **Отказоустойчивость:** Автоматические повторные запросы при сбоях и механизм «спасения» инцидентов (Fallback) при ошибках структурирования JSON.
- **Интерактивный UI:** Веб-интерфейс на Streamlit с разделами сформированного дайджеста, отфильтрованного шума, логов и аналитики метрик.

## Технологический стек

- **Язык:** Python
- **Интерфейс:** Streamlit
- **ML / NLP:** Sentence-Transformers, Scikit-learn
- **Интеграция с LLM:** OpenAI API, OpenRouter
- **Парсинг:** Feedparser, BeautifulSoup4
- **Валидация данных:** Pydantic
